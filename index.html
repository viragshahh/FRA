READING THE RESULTS

What the measures mean

Expected return

The arithmetic average daily return scaled by 252 trading days.

Annualized volatility

Daily standard deviation scaled by the square root of 252.

Value at Risk

A loss threshold at a selected confidence level under a chosen model.

Expected Shortfall

The average loss beyond a tail threshold, under the stated convention.

FORMULA

Parametric daily VaR

VaR = − ( μ + z × σ )

Here μ is the daily portfolio mean, σ is daily standard deviation and z is the normal quantile for the selected confidence level. The displayed result is a positive loss threshold.

95 percent uses z = 1.645. 99 percent uses z = 2.326.

06 • MODEL CHECK

VaR backtesting

Backtesting compares predicted loss thresholds with realized returns. An exception occurs when the actual loss exceeds the forecast threshold.

EXCEPTION FREQUENCY

Observed versus expected exceptions

Preliminary
ConfidenceObservationsExpected rateObserved exceptionsObserved rateKupiec p valueWorkbook result

Failure to reject does not prove a model is perfect. The Kupiec test checks unconditional exception frequency. It does not establish that exceptions are independent or free from clustering.

INTERPRETATION

What a backtest can tell us

Expected rate

The tail probability implied by the chosen confidence level.

Observed rate

The share of valid test observations that breached the forecast threshold.

Kupiec test

A statistical test of whether the observed exception frequency is consistent with the expected rate.

Important limitation

The test period, rolling window and data cleaning rules affect the result.

COVARIANCE MATRIX

Inspect the covariance inputs

Annualized covariance values are shown in decimal return units squared. Positive covariance means two assets tended to move together in the sample. Negative covariance means their observed movements tended to offset.

OPTIMIZATION RULES

How the allocation is chosen

Minimize wᵀ Σ w
  • Weights sum to 100 percent.
  • Each holding has a minimum weight of 1 percent.
  • Expected return must meet or exceed the target when feasible.
  • The objective is minimum variance, not maximum return.

INTERPRETATION

What changes from one window to another?

Because the portfolio selection uses a broad historical dataset, this comparison can contain lookahead bias. A true historical strategy test would need to select stocks and estimate parameters using only information available before each test period.

09 • CONCLUSIONS

Findings and limitations

The conclusion should follow the validated evidence, not precede it. The items below define what must be resolved before final claims are published.

01

Correct the price gaps

The workbook contains missing adjusted prices for Siemens and Divi's Laboratories that appear to have generated artificial 100 percent daily losses. These observations affect risk scores and downstream calculations.

02

Recompute all affected outputs

Recalculate returns, volatility, drawdown, covariance, VaR, Expected Shortfall, backtesting and optimized weights from the cleaned source data.

03

Separate retrospective and predictive claims

Portfolio selection using future data can bias historical comparisons. Clearly state whether results are descriptive or a true out of sample test.

04

Explain model assumptions

Normality, annualization, sample windows, return targets and constraints influence the reported results. Document each choice.
