Important distinction

Parametric VaR assumes a normal distribution using the portfolio mean and standard deviation. Historical VaR uses the observed return distribution. Historical ES averages observations at or below the historical VaR threshold.

What this test does not prove

Failure to reject does not prove a VaR model is perfect. Kupiec tests unconditional exception frequency; it does not test whether exceptions are independent or clustered through time.

Objective

Find the weights that minimize portfolio variance using the selected regime's annualized covariance matrix.

02
Budget constraint
Σwi = 1

All stock weights sum to 100%. The baseline starts at 10% per stock, but optimized weights can differ.

03
Return floor & bounds
wTμ ≥ Rtarget; wi ≥ 1%

Each holding has a 1% minimum weight. The expected return can exceed the target because the constraint is a floor, not an equality.

CALCULATION REFERENCE

Formulas used in the project

A
Daily simple return
Rt = Pt / Pt−1 − 1

Calculated from adjusted closing prices. Valid price observations are required; missing prices must not be interpreted as zero.

B
Sample covariance matrix
Σ = DTD / (N − 1)

Returns are centered by their asset-wise means to form deviation matrix D. The covariance matrix summarizes co-movement between each pair of assets.

C
Parametric VaR threshold
VaRα = μp − zασp

The workbook uses z = 1.645 for 95% confidence and z = 2.326 for 99% confidence. Negative thresholds are returns; positive loss equivalents are their absolute values.

D
Historical Expected Shortfall
ESα = mean(R | R ≤ VaRα)

Average portfolio return in the empirical lower tail. It is usually more negative than the corresponding historical VaR threshold.
